CCH 定制与部分定制要点（来自使用手册摘录）

- RoutingKit 支持预处理（preprocessing）、定制（customization）与查询（query）三阶段工作流。
- 定制阶段通常将权重数组作为输入，输出用于查询的定制化结构。
- 部分定制接口可以只定制一部分边或按块定制，用于减少频繁更新的开销。
- 查询使用定制后的 CCH 结构执行快速前向/反向搜索并合并结果。

映射到本项目的实现要点：
- make_mapper/map_weights 输出的标量权重可以作为定制函数的输入
- 对高频变化（例如突发封路）使用 RoutingKit 的部分定制接口尝试局部更新
- 在实现阶段注意与 RoutingKit 现有 API 对接，优先使用现有的批量权重输入接口
